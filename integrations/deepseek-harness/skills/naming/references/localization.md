# 跨语言命名（本地化与出海，两个方向）

> 用途：product 模式，当名字要跨语言使用时（外国品牌进中文市场 = **译入**；中文品牌出海 = **译出**）。
> 与 `zh-phonetics.md` 的分工：那边讲**中文自身的音形义**（字数、声调、谐音、多音字）；这里讲**跨语言这一步怎么走**，包括策略选择、失误模式与注册现实。
> 强度：**机构**＝代理机构/官方规则；**经验**＝大量案例的共识；**判断**＝本文推断；**未验证**＝无一手来源。

## 0. 一句话立场

跨语言命名不是翻译，是**再造一个本地名**。判定标准只有一个：目标语言的母语者，能不能不借助解释就念对、记住、不出戏。做不到就换策略，而不是把原名的字母强行搬过去。

## 1. 五种策略（译入中文时的分类，同样适用于反向）

| 策略 | 做法 | 什么时候用 | 代价 | 例子 |
|---|---|---|---|---|
| **音译** | 找发音相近的字 | 原名已是强势品牌；人名/地名型品牌 | 选字不当会带出意外联想 | 迪士尼、西门子、奥迪、耐克 |
| **意译** | 译出含义 | 原名有明确含义且该含义在中文里也成立 | 容易削弱独特性、变成品类词 | 苹果、空客、壳牌、大众 |
| **混译（音意融合）** | 一部分取音、一部分取义，或选"音近且义好"的字 | **最有效**，也最难 | 需要母语创意能力，成本高 | 可口可乐、奔驰、星巴克、微信 |
| **随译（另起）** | 不按原名的音或义，直接取一个本地新名 | 原名在本地有障碍、或原名无意义 | 与原品牌脱钩，需重新投资认知 | 汇丰（HSBC）、花旗（Citi）、辉瑞（Pfizer） |
| **不译** | 保留拉丁字母 | 缩写型、技术型、B2B；目标客群本就熟悉英文 | 中文语境里口语传播困难 | IBM、3M、AMD、BCG |

出处（机构/行业盘点）：康信知识产权《外国品牌在中国商标本地化的策略与陷阱》<https://service.kangxin.com/html/1/177/303/13229.html>；译名五分类盘点 <https://www.ciplawyer.cn/articles/133352.html>。

**判断**：混译优先，其次随译，再次音译，最后才是意译——因为"描述性越强，可保护性越弱"（与 `name-types.md` §5 的商标显著性谱系一致）。

## 2. 三个真事故（比原则更有说服力）

1. **Besturn → BESTUNE**（一汽奔腾）：`best + turn` 的混成词，忽略了 `urn`＝骨灰瓮，欧美语境自带负面联想；2018 年改为 `BESTUNE`（best + tune）恰好避开了该词根。**教训：混成词必须逐段查词义，而不是只看整词。**
   - 出处：36 氪/复旦《管理视野》<https://www.36kr.com/p/3947195499265160>
2. **白象 → Baixiang 而非 White Elephant**：`white elephant` 在英语里特指"昂贵而无用的累赘"；改用拼音绕开。**教训：有时不译是最好的译。**
   - 出处：同上。
3. **必应（Bing）**：音译"必应"语义尚可，但与"病"同音，属负面谐音风险。**教训：中文侧必须做逐字+相邻组合的谐音表**（见 `zh-phonetics.md` §3）。
   - 出处：康信同上。

## 3. 译出（中文品牌出海）的四个陷阱

| 陷阱 | 机制 | 对策 |
|---|---|---|
| **拼音直接出海** | `xi/qi/zh/c/q/x` 英语母语者读不出；读不出→记不住→不传播（Al Ries 的公开论述：消费者心智里存的是**声音**不是字母） | 要么改成可发音的罗马化，要么另起英文名，要么用短缩写（ZTE 式） |
| **拼音同形英文词** | `shi`/`cao`/`long`/`wang` 等串在英语里先被读成另一个词 | 把候选丢进英文词典与俚语表各查一次 |
| **方言音译只有本地人懂** | 用粤语/吴语谐音做英文名（如 Pechoin←沪语"百雀羚"），本地有故事，海外无法解码 | 只作为**次级叙事**，主名仍要可解码 |
| **缩写失去可读性** | 为缩短而造 4–5 字母缩写，结果既不可读也不可记 | 缩写只在首字母本身构成可发音音节时使用（ZTE、IBM） |

- **机构/经验**：Al Ries 关于"拼音品牌名在英语世界难以发音与记忆"的论述见界面新闻访谈 <https://www.jiemian.com/article/1367010.html>；上海老字号官方英译名中近一半采用拼音音译，但**书写规范并不统一**（大小写/连写各异）——这篇论文建议「每字拼音首字母大写、逐字独立书写」，见《上海理工大学学报（社会科学版）》<https://jss.usst.edu.cn/shlgdxxbsk/article/pdf/231223612>。
- **判断**：拼音出海不是"错"，而是"只对已经在本地有认知资产的品牌成立"；新品牌用拼音出海＝把最贵的成本（发音教育）留给自己。

## 4. 注册现实（决定策略，不是事后补救）

| 市场 | 要点 | 来源 |
|---|---|---|
| **中国** | 申请在先原则：晚注册＝被抢注后打异议或回购；建议**同时注册**拉丁原标 + 主要中文译名 + 关键图形，必要时对明显恶意谐音做防御性注册 | 康信 <https://service.kangxin.com/html/1/177/303/13229.html> |
| **中国（分类）** | 采用《类似商品和服务区分表》的**子类**管理，与国际实践的宽类目不同；未精确指定商品/服务会留下保护漏洞 | 同上 |
| **节奏** | 建议在市场推出前 **12–18 个月**启动命名与筛查（含语言、文化、在线、商标四类筛查） | 同上 |
| **多形态** | 一个品牌在简繁两个市场若字形不同，必须同时注册商标并固定对应关系，否则会出现第三个"野生写法" | `zh-phonetics.md` §5（判断） |

## 5. 跨语言检查清单（10 项，交付前逐条打勾）

- [ ] 策略已声明：音译 / 意译 / 混译 / 随译 / 不译，**以及为什么**
- [ ] 目标语言母语者念过一遍（录音），能复述、能拼写
- [ ] 混成词已**逐段**查过词义（Besturn 式事故）
- [ ] 已查目标语言的**同形异义词**与俚语（含缩写）
- [ ] 中文侧已过 `zh-phonetics.md` 的 8 项自检（谐音、多音字、输入法可达）
- [ ] 已查目标市场的**方言/地区变体**（粤/吴/闽，或英语的英/美/澳）
- [ ] 译名与原名的**语义不会互相拆台**（例如原名"高端"，译名却廉价）
- [ ] 已确认译名在目标市场的**商标可注册性**（至少 L2 商标库同名初筛，见 `availability.md`）
- [ ] 已规划**多形态注册**（拉丁 + 本地 + 图形 + 防御性变体）
- [ ] 时间线：距上市 ≥ 12 个月时启动（否则只剩"接受风险"这一个选项）

## 6. 不做什么

- **不做翻译服务**：本技能给策略、给检查、给风险；逐字翻译交译者。
- **不判断法律**：抢注、异议、近似判断属商标律师（与 `availability.md` 的 L3 一致）。
- **不编造方言禁忌**：任何"某字在某方言里一定不雅"的断言，没有该方言母语者确认就标**未验证**。
