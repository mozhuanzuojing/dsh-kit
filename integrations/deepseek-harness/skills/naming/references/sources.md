# 证据台账（sources）— 给每条规则挂出处

> 用途：本技能里凡是"因为……所以……"的句子，都应能在这里找到出处或标成**判断**。
> 强度记号：**强**＝多项研究/一手法规；**中**＝单项同行评审或官方文档；**弱**＝方向成立但效应小/有争议；**判断**＝本文推断；**二手**＝转述他人对一手来源的概括。

## 6. 明确**不要**写进技能的说法（无源或过度外推）

| 说法 | 状态 | 处置 |
|---|---|---|
| "47% 的语音搜索会首次听错品牌名" | **无一手来源**；真实测量是 Palanica 2019 的 38.2%/41.5%/8.2%（药品名任务、2019） | 不引用；只用 Palanica 数据并标明任务边界 |
| "名字 1–2 音节最优" | 过度概括，被 Zee et al. (2026) 直接研究弱化（长名在再认上可能更强） | 降级为偏好权重，**禁止用于否决** |
| "4–6 字符是甜区" | **无任何一手来源**（长度研究按音节/长短分组，无字符级阈值） | 已删除 |
| "前元音一定显得更小更快" | 方向有支持，但属"圆/尖"的粗代理，效应量小、跨语言不一致 | 只作 L2 决胜层，且必过品类效价检查 |
| "语音象征跨语言普遍成立" | 只有 bouba/kiki（圆/尖）有强跨语言证据；其余部分复现 | 限定到 L1 层 |
| "流畅的名字更好，所以越流畅越好" | 与"易记"方向相反（§3）；且流畅→股价只有单研究且再检验未核实 | 必须成对呈现并按 KPI 条件化 |
| "描述性名字不能注册" | 法理上是"需第二含义 + 成本高 + 通常不能 ITU"，不是绝对禁止 | 改为成本/程序表述 |
| "去 USPTO TESS 做淘汰检索" | TESS 已于 **2023-11-30 退役** | 改为 USPTO Trademark Search |
| "域名必须 .com" | 被大量反例否定（Tesla/Peloton/Square） | 改为"域名缺失不是否决项" |

## 7. 引用规范（写给后续维护者）
1. 一手来源优先：论文给 DOI；法规给案号/官方链接；机构文档给原文 URL。
2. 二手转述必须标"二手"，并尽量同时给原始出处。
3. 数字必须能追到具体论文/页面；追不到就写"未验证"，**不许**为了让论证好看而保留。
4. 本文件与 `principles.md` 的"来源"行必须一致：`principles.md` 新增结论时，同步在本文件登记。

## 11. UI 层命名（界面文案 / CSS / 无障碍 / i18n）

| 结论 | 出处 | 强度 |
|---|---|---|
| 可访问名必须包含"动作 + 对象"，图标按钮必须有可读名；装饰图 `alt=""` | W3C《WCAG 2.2》1.1.1、2.4.6、4.1.2 <https://www.w3.org/TR/WCAG22/> | **机构** |
